GLEZRUDA SECURITY V1.2 - ACTIVACION OFFLINE

1. El cliente abre GlezRuda Security y copia el ID DEL EQUIPO.
2. En su PC de administrador abra key_generator.py (o su EXE privado).
3. Pegue el ID del equipo.
4. Seleccione: 30 dias, 90 dias o 1 ano (365 dias).
5. Pulse GENERAR KEY y envie solamente la KEY al cliente.
6. El cliente pega la KEY en la pantalla de activacion y pulsa ACTIVAR.
7. La licencia queda vinculada a ese equipo y vence en la fecha indicada.

SEGURIDAD:
- NO distribuya key_generator.py ni el EXE del generador.
- El antivirus puede distribuirse al cliente; el generador debe permanecer privado.
- Si cambia el secreto de firma, debe cambiarse exactamente igual en main.py y key_generator.py antes de compilar.

NOTA:
Este sistema es una licencia offline basica. Para una proteccion comercial mas resistente a manipulaciones conviene migrar a firmas asimetricas y validacion opcional mediante servidor.
