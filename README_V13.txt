GLEZRUDA SECURITY V1.3
======================
NOVEDADES
- Protección en tiempo real activable/desactivable.
- Vigila Downloads, Desktop y Documents del usuario.
- Analiza archivos nuevos o modificados mediante SHA-256.
- Cuarentena automática cuando una firma coincide.
- Alertas y eventos visibles en el panel.
- Conserva activación offline de 30, 90 y 365 días de V1.2.
- Microsoft Defender permanece activo; esta aplicación es complementaria.

PRUEBA SEGURA
Puede usarse el archivo de prueba estándar EICAR para comprobar la detección por firma. La aplicación incluye únicamente su hash SHA-256, no el contenido de prueba.

IMPORTANTE
El generador de claves es privado y no debe entregarse junto con la copia del cliente.
Esta V1.3 no utiliza drivers kernel ni pretende sustituir un antivirus comercial completo.
